# Real United Website

A responsive, dark-and-gold club website built with plain HTML, CSS, and JavaScript.

## Included
- `index.html` — website structure and content
- `styles.css` — responsive layout, colours, animations, and mobile navigation styling
- `script.js` — mobile menu, current year, and active navigation state
- `assets/real-united-logo.jpg` — your supplied Real United artwork

## Run locally
1. Extract the ZIP file.
2. Open the `real-united-website` folder.
3. Double-click `index.html` to preview it in your browser.

For the best local development experience, open the folder in VS Code and use the **Live Server** extension.

## Customize
- Replace the sample squad cards in `index.html` with real player names, positions, and photos.
- Update the contact email in the `mailto:` link in `index.html`.
- Change colours near the top of `styles.css` in the `:root` section.
- Replace `assets/real-united-logo.jpg` if you have a transparent PNG version of your crest (update the image paths if you change the filename).

## Publish online
You can deploy this static website to GitHub Pages, Netlify, or Vercel. No build step or package installation is required.
